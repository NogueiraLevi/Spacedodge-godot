# Space Dodge 🚀

Jogo arcade 2D desenvolvido com a engine **Godot 4**.
O objetivo é desviar dos meteoros e sobreviver o maior tempo possível.

## 🛠️ Tecnologias
- **Engine:** Godot 4.3
- **Linguagem:** GDScript
- **Arte:** Pixel Art (Piskel)

## 🎮 Como Jogar
1. Vá na aba [Releases](https://github.com/NogueiraLevi/Spacedodge-godot/releases/tag/v1.0) aqui do lado direito.
2. Baixe o arquivo `.zip`.
3. Extraia e execute o `SpaceDodge.exe`.
